# 泥之子Godot白盒V1.0交付说明

当前源码为C#，需要Godot 4.7.2 .NET版及.NET SDK。打开和构建方法见 `CSharp_Migration_V1_0.md`。合并main后运行输出统一写入 `tests/output/`。

当前动作规则：泥闪避后1秒、攻击后1.5秒曲线减速，攻击后摇最后0.5秒允许格挡；水格挡CD3秒，成功重置格挡CD和攻击间隔。旧版2秒线性闪避减速已停用。


已直接修改工程：`D:/GAMEOFF/son-of-mud`。实际引擎为Godot4.7.2.stable.official.ed1daf0bf，渲染器为Compatibility，运行日志显示OpenGL3.3 / NVIDIA RTX4060 Laptop GPU。

## 运行入口

- 打开本工程`project.godot`，F5进入中文主菜单，选择“新流程·苏醒”“继续”或“独立测试场”。
- 主菜单：`res://assets/scenes/ui/main_menu.tscn`。
- 形态测试场：`res://assets/scenes/whitebox/tests/form_lab.tscn`，也可在流程中按F2进入。
- 主线场景：`res://assets/scenes/whitebox/levels/M01.tscn`至H03，共23个。没有T07、T08或H04～H08。
- 唯一玩家控制器：`assets/scripts/player/MudPlayer.cs`。

## 操作

|按键|功能|
|---|---|
|A/D|左右移动|
|空格/W|跳跃；二段跳解锁后空中再按一次|
|Q|水/泥形态切换|
|Shift|闪避|
|K|格挡；松开再按才能发起下一次动作|
|J|攻击；空中按住S+J在未解锁重压下砸时为向下普通攻击|
|空中S+J|解锁后使用重压下砸|
|贴墙+朝墙方向+W|攀墙，需独立能力解锁|
|水中W/S|潜游升降，需水形态且已解锁潜游|
|E|最近发光节点或房门交互；捷径先破门，再按一次通行|
|B|测试场或M04/C03/H02落地待机时选择泥跳跃模组|
|F2|独立测试场|
|F6|只在测试场开放调试能力；不会解锁高跳升级|

|R|从最近休整/战斗房间入口重试|

保留了原有输入项与绑定，缺少的动作已添加到project.godot。InputDefaults只作缺项补充，不清空输入映射。旧F2巡检动作绑定仍保留，但主线不提供穿越门槛的飞行巡检；F2用于测试场。

## 能力与主线流程

1. 本原型初始水形态，格挡与切换已可用，M01提供攻击源与说明，M05前可练习格挡。
2. M05成功格挡指定占位攻击会使守坑人僵直，并提供易伤窗口。E开始挑战，战斗封锁双向门；R死亡重试未击败战斗；胜利永久开门。
3. T01入口安全节点获得二段跳，必须实际完成二段跳高台教学才开放T02；T02获得攀墙并爬到上层，才开放T03。因此T04前已获得并练习两项能力。
4. T03操作水闸，3秒洪水色块演出后退水，开放后续；可读「洪水之后」。
5. T04为锁定位置下砸/换位失衡的龙蛇占位战。墙面、侧平台和二段跳空间已保留。冲拳、合掌、抓握三套正式动作尚未制作，不将其称为已完成招式。
6. T05保留2.5H纵向空间，含塔姆图与流星雕像；向上抵达城市出口。T06黄/红功能分区使用一个场景，不生成重复房间。
7. C03与伊吉交谈、获得重压下砸；C04入口获得潜游。两个能力获取点均位于此前已有能力可达的安全地面。
8. C04池底读征兆、C05击碎裂板读雕像、C06顺序读征兆，分别写入完成标记。城市不增加解肝大祭司Boss。C07要求三个街区完成且已见伊吉。
9. C07→C08→T06→H01。T06侧E破门，再E可经捷径返回T05；首次T05无法反向开启。
10. H01一场景内从下向上登塔，按顺序经过角冠、金耳环、项链、胸饰、腰带、手镯、长袍七道门并读对应泥板。H02休整与能力应用，H03依次塔姆图、伊姆杜两阶段，之后触发真相及醒来/回去睡分支。

最新.ai的H区在导航图中向下排列；PDF叙事要求向上登塔。本版把图的上下排布解释为导航连接，在H01内部向上攀登，没有把剧情改成下潜。C08绿色/红色部分同样作为一个过渡场景。芦苇泽、高崖、眼之殿和M02下方水域只留扩展说明/数据接口，不建立额外房间或可传送边。

## 存档与模块

- Progress管理能力、街区、七道门、Boss、捷径、剧情节点、最近房间和检查点。JSON带version=1，先写临时文件再替换；路径为`user://mudchild_whitebox_v1.json`。
- 测试能力为独立覆盖层，测试场不写正式存档；F8新流程清空覆盖层。恢复正式进度后测试解锁不残留。
- RoomTravel继续提供原来的go_to_room入口，校验真实资源路径，延迟换场并定位目标Marker；额外携带生命/形态/冷却/减速/增伤资格。
- 过门清空空中落地伤害资格与速度；出生点不与触发门重合，E主动交互，抵达锁定0.45秒。
- action_state管理动作互斥；player_combat管理攻击形状、命中去重和增伤消费；attack_ledger管理敌人攻击ID去重；form_config、prototype_rules管理资源；whitebox_room调度房间数据，whitebox_geometry搭建地形，whitebox_events执行交互事件。
- 旧控制器已被唯一状态控制器替换，玩家场景路径仍是`res://assets/scenes/player/player.tscn`。未引用不存在的`res://scenes/player.tscn`。
